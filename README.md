# 現場メモ → 見積たたき台 v2

現場で拾った数量・メモから、原価概算と各AI向けプロンプト（Claude／Perplexity／積算チェック）、案件記録用Markdown、Excel貼り付け用データを生成するスマホ向けツール。

## ファイル構成
- `index.html` … 画面（HTML／CSS）
- `app.js` … 本体ロジック（`index.html` から読み込み。CSP を厳格にするため分離）
- `manifest.webmanifest` / `icon-192.png` / `icon-512.png` … ホーム画面追加（PWA）用
- `sw.js` … オフライン起動用（現場の電波が弱い場所向け）

## 主な機能（v2）
- 入力の自動保存（ブラウザ内 localStorage）と案件履歴の保存・読込・削除、JSON書き出し／読み込み
- 数量 × 単価 × 単位、行ごとの金額表示、外注費は「一式＝数量1」
- 法定福利費（任意）、消費税、見積金額の千円処理（設定で切替）
- リスク選択と原価項目の整合チェック（足場・解体・アスベスト調査・廃材処分など）
- 品名の入力候補（保存済み案件から自動学習、単価も補完）
- ライトーダークテーマ（屋外向けにライト推奨）

## セキュリティ方針
- 外部サーバーへの送信なし。データはこの端末のブラウザ内（localStorage）にのみ保存
- Content-Security-Policy（`index.html` の meta）で外部スクリプト・外部通信・インラインスクリプトを禁止（`script-src 'self'`）
- 外部フォント（Google Fonts）への依存を廃止し、端末のシステムフォントを使用（IPアドレス等の第三者送信なし・オフラインでも表示が変わらない）
- 案件履歴・入力候補・JSON取り込みのデータは、画面に出す前に型・長さ・許可値を検証（HTMLとして解釈させない）
- JSON取り込みは 5MB 上限・案件は最大200件
- Service Worker は自サイトの GET の正常応答のみキャッシュ
- 設定パネルに「この端末の全データを消去」を用意（端末の共用・譲渡前に実行）

## 更新方法
GitHub Pages にこのリポジトリのファイルをそのまま配置。`sw.js` の `CACHE` 名を変えると旧キャッシュが破棄されます。
